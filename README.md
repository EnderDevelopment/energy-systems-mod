# Energy Systems Mod

A comprehensive Minecraft mod for energy systems

## Features

- Energy cells as a new item type
- Energy generator and consumer blocks for energy production and consumption

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

### Items

- **Energy Cell**: A new item that can store and transfer energy.

### Blocks

- **Energy Generator**: A block that generates energy.
- **Energy Consumer**: A block that consumes energy.

## Configuration

The mod does not have a configuration file yet, but it is planned for future updates.
